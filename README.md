# Veritass

Field manual for Veritass, a Royal Paladin on Refugia (Tibia): gear, imbuement costs, spells, Wheel of Destiny, hunting guides, hunt log and progress.

The whole site is one file, `index.html`. It needs no build step: GitHub Pages serves it as is.

## Updating

Replace `index.html` with a new version and commit. GitHub Pages republishes within a minute or two.
